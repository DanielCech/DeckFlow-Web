We take accessibility seriously.
Learning should meet you where you are.

JustFlip! is built to make active recall usable with the tools many learners rely on. This is a living report of what is implemented, what is ready for device validation, and what we deliberately do not claim yet.

The honest headline

The accessibility implementation is substantial and the automated audit now runs across all 12 primary screens. The remaining work is chiefly human: device passes for each platform, voice-only testing, and measured contrast values. A short list of code follow-ups is still open, and each one is named in the table below.

01

A useful report, not a marketing checkbox.

Apple’s Accessibility Nutrition Label is a public promise. We are treating it as an evidence boundary: a feature is only claimable after its common tasks work on the device category where we publish it. Our label is therefore empty today — the categories below are published one at a time, per device, as each pass completes.

The common-task gate.

A label is only honest when the complete study workflow works with the setting enabled. These are the eight tasks used for device validation.

Common tasks used to validate each accessibility category.
IDCommon taskWhat is exercised
CT1OnboardingComplete or skip first-run onboarding.
CT2Create contentAdd an interest, deck and card, including an image and its description.
CT3ReviewStart a review, flip a card, grade it and finish the session.
CT4Browse and organizeOpen interest → deck → cards; search; move or merge; set priority; postpone.
CT5StatisticsOpen Statistics, change scope, and read retention, forecast and heatmap.
CT6Settings and dataChange a setting, view sync status, export statistics and open the starter library.
CT7Purchase flowOpen the Pro paywall and read plan and comparison details.
CT8ImportImport a .flashcards, CSV or Anki file through the document picker.
Our rule for publishing

One blocked task keeps a category unclaimed for that device.

Automated audits give us a useful regression gate, but code evidence is not device certification. The remaining validation covers iPhone, iPad and Mac Catalyst, with Larger Text tested on iPhone and iPad. This page will change as those passes are completed.
