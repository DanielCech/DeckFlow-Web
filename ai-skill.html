The AI Prompt page makes quick text-only cards in any chat. This is the other way: add one skill to your AI coding agent and it builds full JustFlip decks — with images, audio and Markdown — straight from the files on your disk. No copy-pasting, no hand-written JSON.

Install the skill Just text? Use the prompt page
What's different

A chat AI returns a text-only .flashcards file. Your coding agent can read local images, audio and notes, so it returns a .flashcards.zip bundle with the media already attached — ready to open in JustFlip.

01

Add the JustFlip skill to your agent.

One command installs the justflip-create-flashcards skill into any agent that supports skills.sh. Run it once in your project, then just ask in plain language.

Images

Attach local photos and diagrams to either side of a card.

Audio

Bundle pronunciation clips and spoken-form hints for TTS.

Markdown & math

Rich formatting, code blocks and LaTeX, rendered natively in-app.

02

Point it at a folder. Ask in plain words.

Say you have a folder of mushroom photos named after each species. Ask your agent to turn the file names into questions and the photos into answers — it reads the folder, builds the deck and packages the images for you.

~/mushrooms — coding agent

$ ls mushrooms/

fly-agaric.jpg   chanterelle.jpg   porcini.jpg

morel.jpg        death-cap.jpg    shiitake.jpg

❯ This folder contains images of mushrooms. Take the file names as the question text and the mushroom image as the answer. Prepare the flashcards deck.
